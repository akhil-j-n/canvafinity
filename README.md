# Bushel - Grocery Store Bootstrap Template

It is a free version of Bushel Grocery Store Template, A clean and modern Bootstrap-based HTML template for a grocery store or fresh food website.

## Overview
This project includes multiple pages such as home, products, cart, deals, blog, contact, and locations.

Bootstrap 5.3.3 and the Google Fonts (Anton, Work Sans) are loaded via CDN in each page's `<head>`.

## Technical Brief
- Built with HTML5 and Bootstrap for a responsive layout.
- Uses reusable sections and modern UI styling for fast customization.
- Suitable for grocery, supermarket, organic food, and fresh produce websites.
- Easily editable for branding, colors, content, and product sections.
- Optimized for desktop and mobile browsing.
